# BongoCatClicker

Утилита для Windows, которая генерирует события клавиатуры и мыши через стандартный Windows API
`SendInput` — тот же механизм, которым пользуются настоящая клавиатура и мышь. Не трогает файлы,
процесс или память какой-либо игры, сетевого доступа нет.

*[English version](README.md)*

## Возможности

- Отправляет события нажатия/отпускания для цифр Numpad и/или F13–F24 — клавиш, которые есть в
  модели ввода Windows, но которых нет ни на одной физической клавиатуре, поэтому на них не
  реагирует ничто другое в системе.
- По желанию кликает мышью в случайных точках внутри области, которую вы растягиваете на
  экране — она обозначена тонкой красной рамкой, прозрачной для кликов, пока задана. Область не
  сохраняется между запусками.
- Глобальные горячие клавиши из любого окна: **F6** — старт, **F7** или **Esc** — стоп.
- Автопауза при реальном движении мыши или печати, включена по умолчанию — не мешает работе.
- Режим «только клавиши» — самый быстрый; мышь и гибрид добавляют накладные расходы на
  позиционирование курсора.
- Не кликает по собственному окну; повторный запуск просто разворачивает уже открытое.

## Установка

Нужна Windows 10/11.

### 1. Установить Python (пропустите, если он уже есть)

Нажмите **Win + S**, введите `cmd`, нажмите Enter, чтобы открыть **Командную строку** — от
администратора запускать не нужно, при необходимости Windows сама покажет запрос на
повышение прав во время установки. Сначала проверьте:

```
python --version
```

Если видите номер версии — Python уже есть, переходите к шагу 2. Если нет:

```
winget install -e --id Python.Python.3.12
```

Если в ответ `"winget" не является внутренней или внешней командой...` — на вашей версии
Windows его просто нет (частый случай на более старых сборках Windows 10). Тогда скачайте
установщик с [python.org](https://python.org) и отметьте **«Add python.exe to PATH»** при
установке. В любом случае закройте и снова откройте командную строку и проверьте
`python --version` ещё раз.

### 2. Скачать проект

Перейдите на главную страницу репозитория — https://github.com/Iponai/BongoCatClicker — а не
эту страницу с README, там такой кнопки нет. Там нажмите зелёную кнопку **Code** →
**Download ZIP**, затем распакуйте архив в удобную папку.

### 3. Если работаете с Bongo Cat — сначала включите ей режим администратора

Bongo Cat должна быть запущена от администратора, иначе ввод не будет засчитываться, пока
активна эта программа (или любое другое окно с повышенными правами). В Steam: Библиотека →
Bongo Cat → **Управление** → **Просмотреть локальные файлы** → правый клик по
`BongoCat.exe` → **Свойства** → вкладка **Совместимость** → отметить **«Запускать эту
программу от имени администратора»**.

### 4. Запустить программу

Откройте распакованную папку и запустите **`start_as_admin.bat`** — он нужен именно потому,
что Bongo Cat теперь тоже запущена с повышенными правами (шаг 3). Обычный `start.bat`
используйте, только если приложение, которому вы отправляете ввод, *не* запущено от
администратора.

По желанию: дважды кликните **`make_shortcuts.bat`** в этой папке — добавит ярлыки с
иконкой-котиком, просто для приятного визуала, внутри они запускают те же
`start.bat`/`start_as_admin.bat`.

## Использование

Начните с режима «только клавиши», галочка на F13–F24, удержание и пауза — по 20 мс. Если
нажатия пропускаются, поднимите оба значения до 30 мс. Цифры Numpad печатаются в активное окно,
поэтому для фоновой работы используйте F13–F24; в режиме мыши клик уходит туда, что под
курсором, так что наводите область на пустой рабочий стол или целевое окно.

## Если ввод не засчитывается

Обычно дело в одном из двух:

- **Разрыв привилегий.** Windows блокирует получение ввода процессом без повышенных прав, пока
  активно окно с повышенными правами. Запустите целевое приложение тоже от администратора.
- **Слитный клик.** Некоторые счётчики засчитывают нажатие, только когда down и up приходят как
  два отдельных, разнесённых по времени события, а не одной мгновенной парой — именно так многие
  инструменты синтетического ввода шлют «клик». Эта программа всегда отправляет их раздельно.

## Про антивирусы

Не упакованный, не обфусцированный Python-скрипт, без сети и без компиляции в `.exe`. Проверено
полным сканированием Microsoft Defender (`MpCmdRun.exe -Scan -ScanType 3`) — чисто.
Срабатывание где-то ещё по общей эвристике «PUA:AutoClicker» — это общая категория для любых
инструментов, эмулирующих ввод, не признак вредоносного кода.

## Структура репозитория

```
bongo_clicker.py           основная программа (EN/RU встроены)
run.ps1                     загрузчик (ищет Python, корректно передаёт путь)
start.bat / start_as_admin.bat
make_shortcuts.bat          опционально: добавляет ярлыки с иконкой кота
assets/                     иконка кота (уже готова - сама появится в панели задач)
tools/                       пересборка иконки/ярлыков; запускать это не нужно
```
